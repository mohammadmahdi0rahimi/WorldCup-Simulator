# Simulator-e Jam-e Jahani - Noskhe-ye Mohammad Mahdi

Sakhtar-e barname az chand module-ye sade tashkil shode ast. Menu faghat ba
`WorldCupSimulator` kar mikonad va class-e asli, class-haye koochaktar ra
hamahang mikonad. In jodasazi peyda-kardan-e eshkal va test-e har ghesmat ra
asan-tar mikonad.

Masooliat-e module-ha:
- Team: dade va raftar-e har tim
- Match: didar, emtiyaz va matn-e natije
- Group: jadval va tim-haye soodkarde
- KnockoutStage: ejra-ye yek dor-e hazfi
- WorldCupSimulator: ghorekeshi, jam-e kamel, darsad va bracket

Ejra-ye barname:
`python worldcup_simulator.py`

Kontrol-e test-ha:
`python -m unittest discover -s tests -p "test_*.py" -v`
